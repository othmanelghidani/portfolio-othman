# Othman El Ghidani — Portfolio

Personal portfolio website: 5th-year engineering student in Big Data & AI (Télécom Nancy), looking for a 6-month end-of-studies internship (PFE) in 2027 in Data Science, AI/ML or Data Engineering.

**Live site:** https://othmanelghidani.github.io/portfolio-othman/

## Content

- Profile, skills, internships, education, certifications and languages
- Featured projects, linked to their GitHub repositories
- Contact links (email, LinkedIn, GitHub)

## Tech

Static site: HTML, Tailwind CSS (CDN), custom CSS and vanilla JavaScript. It has no build step and is hosted on GitHub Pages.

The page content is defined in the `portfolioData` object in `script.js`.

## Run locally

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.
